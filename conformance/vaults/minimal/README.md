# minimal — conformance vault

A complete, small Basalt vault. A runner points its implementation at
`vault/`, rebuilds every index, and compares against `expected/` byte for
byte, excluding the fields §13.2 lists (`generated`, `etag`).

What this vault exercises deliberately:

- **A dangling link** (`Does Not Exist` in Hexes.md) — must appear as an edge
  with `to: null`, not be dropped.
- **A fenced code block** containing `[[Fenced]]` — must produce no edge (§9.1).
- **An alias** (`Hexagons` on Hexes.md) — reachable via resolution step 4.
- **An anchored link** (`Columns#jointing`) — resolves the node and the anchor.
- **An asset with no frontmatter** — its id comes from the entry sidecar (§6.1).
- **A private note** (`Columns.md`) whose deny names `g:staff` rather than
  `everyone`. This is the instructive part: `everyone` matches every request
  including the owner's, and explicit deny precedes explicit allow (§8.4), so
  denying `everyone` here would lock out `u:carter` too despite the
  `full_control` grant beside it. A DACL cannot express "everyone except
  Carter" — the idiom is to deny a group the owner does not belong to. A
  gatekeeper test checks that `u:carter` reads it, `u:reader` gets 403, and a
  path that does not exist gets 404.
- **A root ACL granting only `traverse` and `list`**, with `ci` so folders
  inherit them and no `read` anywhere. Without a root `traverse` grant, §8.5
  denies every request in the vault whatever the leaf ACLs say — the
  accidental lockout §8.5 warns about.
- **An asset embed across folders** (`![[diagram.png]]` in `Start Here.md`
  pointing at `Assets/diagram.png`) — only resolvable because §9.2 step 5
  matches the full basename and not just the stem.
- **`audience: gated`** — so the anonymous ceiling (§12.2) is live.

`expected/` is generated by the reference implementation and reviewed by hand.
Regenerate with `node ts/bin/basalt.mjs conformance-regen`, and review the
diff: a change here is a change to the protocol's observable output.
