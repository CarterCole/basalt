# Columns

A small public vault about the rock this protocol is named after, and a
working demonstration of what [[Basalt]] publishes: resolved wikilinks,
backlinks, a local graph, and notes that are deliberately *not* here.

Start with [[Columnar Jointing]] for the mechanism, or [[Basalt]] for the
material itself. The [[Giant's Causeway]] is where most people meet it.

![[hexagons.svg]]

## What to look at

- Every link below is resolved through the same algorithm that built
  `index/links.json`, so the page and the index cannot disagree.
- The **Linked from** panel under each note is derived, not authored.
- This vault contains a draft that is excluded from publication. You will not
  find it, and that is the point — see [[Basalt]] for how.

## Not everything is public

There is a note in `Drafts/` that denies the `publish` right. On the live
gatekeeper an editor can read it; in a static export it does not exist at all.
A link to it renders as restricted rather than disappearing, so the graph
stays honest: [[Unfinished Thoughts]].
